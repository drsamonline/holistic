# Holistic 2.7.0

The app is complete. This release adds the support block.

### Downloads

| Asset | Size | Notes |
| --- | --- | --- |
| `holistic.html` | 193 KB | One self-contained file, QR inlined. Works offline. |
| `holistic-android.apk` | ~4.3 MB | Capacitor debug build. Unsigned. |
| `holistic-windows-setup.exe` | ~78 MB | NSIS installer. Unsigned. |

### What's new

- **Support block** in Profile and on the landing page — UPI with a scannable QR, Ko-fi, PayPal, Amazon author store, app index.
- **Copy UPI ID** button.
- **Other apps** — six sibling projects linked from inside the app, all 30 on the landing page.

### Notes

- The QR is inlined as a data URI in the single-file build, so it works with the Wi-Fi off.
- Nothing is gated. The app still makes zero network requests.
